# E-Commerce UI & API Automation Framework

## Overview

This project is an End-to-End (E2E) test automation framework developed in **Java** for the **Automation Exercise** e-commerce website. It combines **Selenium WebDriver** for UI automation and **REST Assured** for API testing, providing comprehensive test coverage across both the user interface and backend services.

The framework follows the **Page Object Model (POM)** design pattern to improve code readability, maintainability, and scalability. **TestNG** is used for test execution, assertions and to provide an organised test structure, while **Maven** manages project dependencies.

## Tech Stack

- Java
- Selenium WebDriver
- REST Assured
- TestNG
- Maven
- Page Object Model (POM)
- Git



## Implemented Test Cases are as follows: 

* 1 Positive Login Test
* 2 Negative Login Test
* 3 Add Product to Cart
* 4 Remove Product from Cart
* 5 Add Multiple Items in Cart
* 6 Remove items from multiple cart
* 7 Checkout Cart Flow   

## Framework Features Include: 

* UI & API Automation
* Page Object Model (POM)
* TestNG BeforeMethod, Test and AfterMethod
* TestNG Assertions
* Reusable Page Classes
* Maven Dependency Management
* End-to-End Test Coverage
* REST Assured Request Validation
* Git Version Control
